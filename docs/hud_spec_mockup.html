HUD Spec — read me

This is a specification artefact, not shipped product. It is the visual reference for the Phase 7 UMG build. ART_DIRECTION.md §8 is the authority — where this file disagrees with §8, §8 wins.

All telemetry shown is simulated. No number in this mockup has been measured, and none may be copied into a README or budget table.

The two §8.2 corrections, implemented

  • RPM strip adjacent to gear, not floating across the frame — shift point and gear are read together.
  • Minimap generated from the spline, sampled at fixed arc length. Never an authored texture.

Non-negotiables carried from §8.3

  • No backdrop blur. Real per-frame GPU cost for a subtle effect. The premium-frontend skill independently measures backdrop-filter at 15–30% FPS on mid-tier hardware, so both the art direction and the performance guidance agree.
  • Monospace, tabular numerics everywhere. Proportional digits jitter as values change and it reads cheap.
  • Panels ~72% opacity, 6px radius, no border.
  • Labels 12px uppercase muted; values large and high contrast.

Accessibility (§8.4)

  • Sector delta uses sign and arrow, not colour alone.
  • HUD scale 0.75×–1.5×; minimal-HUD and photo-mode toggles.
  • Everything inside a 5% safe margin.
  • prefers-reduced-motion stops rain, lane rush and sign flicker.

Proposed §8 amendment

The TC / ABS / OFF-TRACK flags top-left are not in §8's table. Phase 3 surfaces all three (UVehicleAssistComponent::GetActiveInterventions, UVehicleSurfaceSensorComponent::GetOffTrackWheelCount) and a driver needs to know when an assist intervened. Flagged as a proposed amendment rather than assumed — approve it and §8.1 gains a row.

UMG binding map for Phase 7

  • Speed → IMidanVehicleInterface::GetForwardSpeedKmh()
  • RPM → FMidanVehicleFrameState::EngineRPM ÷ MaxRPM
  • Gear → FMidanVehicleFrameState::Gear
  • Position / Lap → IMidanRaceStateInterface (10 Hz, not per frame)
  • Sector delta → UMidanLapTimingSubsystem best-sector
  • Minimap → IMidanTrackInterface::GetTransformAtDistance() sampled at fixed arc length
  • Flags → UVehicleAssistComponent, UVehicleSurfaceSensorComponent
